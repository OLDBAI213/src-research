## 🛠️ 技术选型

经过对 Shannon（3.9万⭐）、PentAGI（8.2k⭐）、Pentest-Swarm-AI（1.1k⭐）的深度分析，选择 **PentAGI** 作为主力框架：

- ✅ 黑盒测试（SRC不需要源码）
- ✅ 45%检出率（开源组最高）
- ✅ 支持本地Qwen3.5（中文天然优势）
- ✅ MIT许可证（最宽松）
- ✅ 13+专业Agent，20+安全工具
