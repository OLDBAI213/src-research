# 注册问题解决方案

## 问题本质

SRC平台注册需要：手机号验证 → 实名认证 → 2FA → 支付绑定

每一步都需要"人"的操作。但**不是每一步都需要你亲手操作**。

---

## 解决方案

### 1. 接码平台（解决手机号验证）

有API的接码平台，可以用脚本自动获取手机号+接收验证码。

| 平台 | 覆盖 | API | 价格 | 中文 |
|---|---|---|---|---|
| **SMS-Activate** | 全球180+国家 | ✅ Python包 `smsactivate` | $0.1-2/次 | ✅ |
| **5sim.net** | 全球多国 | ✅ REST API | $0.05-1/次 | ✅ |
| **SmsBower** | 全球+86中国号 | ✅ API | ¥1-5/次 | ✅ |
| **GrizzlySMS** | 全球 | ✅ API | $0.1-1/次 | ✅ |

**工作流程**：
```
1. 接码平台API → 购买临时手机号（¥1-5）
2. 用该手机号注册SRC平台
3. 平台发送验证码 → 接码平台API自动接收
4. 填入验证码完成注册
5. 废弃临时手机号
```

**Python集成**：
```python
import smsactivate  # pip install smsactivate

# 1. 获取临时手机号
client = smsactivate.Client("YOUR_API_KEY")
number = client.get_number(service="vulbox", country="cn")

# 2. 用number去注册SRC平台...

# 3. 获取验证码
code = client.get_code(number)
# code = "123456"
```

### 2. 实名认证（需要你操作）

这一步没法绕过。但可以优化：

**方案A：用一个固定手机号**
- 你的主号注册一次，长期使用
- 好处：实名认证通过率高，不被风控
- 坏处：一个手机号只能注册一个账号

**方案B：用接码平台+身份证照片**
- 有些平台允许"手机号验证+身份证照片"分开做
- 手机号用接码，身份证照片用你自己的
- 但很多平台要求手机号和实名信息一致

**推荐**：方案A更稳。用主号注册核心平台（漏洞盒子/补天），接码平台注册国际平台（HackerOne/Bugcrowd，这些不一定需要中国手机号）

### 3. 2FA（双因素认证）

**方案**：
- 漏洞盒子/补天：可能需要短信2FA → 用主号
- HackerOne/Bugcrowd：支持TOTP（Google Authenticator） → 注册后设置
- 我可以帮你配置TOTP：用Python的 `pyotp` 库生成密钥+验证

### 4. 支付绑定（提现用）

**国内平台**：银行卡/支付宝
**国际平台**：PayPal/Payoneer
**Web3平台**：加密货币钱包

这一步必须你操作，我没法代替。

## 实际执行流程

### 第一次注册（15-30分钟，需要你在）

```
你做的：
1. 打开代理
2. 我打开注册页面
3. 你输入手机号（主号或接码平台的号）
4. 你接收验证码告诉我
5. 你完成实名认证（如果需要）
6. 你绑定支付方式（如果需要）

我做的：
1. 打开注册页面
2. 填写用户名/密码/邮箱
3. 自动获取验证码（如果是接码平台的号）
4. 完成注册后的安全设置
5. 加入项目+读规则
6. 确认登录态保存
```

### 后续登录（全自动）

注册一次后，登录态保存在：
- `cookies/` 目录（JSON格式）
- `browser_profile/` （持久化Chrome profile）

后续登录我自动处理，不需要你操作。
