# 工具×方法论 — 完整执行手册

## 核心思路

**方法论决定打哪，工具决定怎么打。** 每个阶段都有对应的工具，不是随机用。

## 第一步：最大化线索

### 1.1 子域名枚举

| 工具 | 用途 | 优先级 |
|---|---|---|
| **subfinder** | 被动子域名枚举 | ⭐⭐⭐⭐⭐ |
| **crt.sh** | 证书透明度查询 | ⭐⭐⭐⭐ |
| **httpx** | 存活探测+技术指纹 | ⭐⭐⭐⭐⭐ |
| **dnsx** | DNS解析验证 | ⭐⭐⭐ |
| **fofa/hunter** | 被动资产搜索 | ⭐⭐⭐ |

```bash
subfinder -d target.com -silent > subs.txt
httpx -l subs.txt -silent -status-code -title tech-detect > alive.txt
```

### 1.2 前端JS分析（最高ROI）

| 工具 | 用途 | 优先级 |
|---|---|---|
| **curl** | 下载JS文件 | ⭐⭐⭐⭐⭐ |
| **grep** | 提取端点/密钥/配置 | ⭐⭐⭐⭐⭐ |
| **jsluice** | JS端点提取 | ⭐⭐⭐⭐ |
| **katana** | 爬虫+JS渲染 | ⭐⭐⭐⭐ |

```bash
# 下载所有JS
curl -sL "https://target.com" | grep -oP 'src="[^"]*\.js"' | ...

# 提取API端点
grep -oE '/api/[a-zA-Z0-9/_-]+' *.js | sort -u

# 提取密钥/配置
grep -oE '(api[_-]?key|token|secret|password|app_id)[\"\s:=]+[\"\x27][^\"\x27]+' *.js
```

**核心结论**：

- **python** 是第二通用工具，用于批量/复杂逻辑
- **攻击记忆** 从第3步开始持续使用

- **browser** 只在需要登录态交互时使用
