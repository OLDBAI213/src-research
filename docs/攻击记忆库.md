## 漏洞教训

| 漏洞 | 教训 | 误报陷阱 |
|---|---|---|
| IDOR | 要展示对方数据在响应中 | 200≠漏洞 |
| SSRF | DNS callback不要报 | 必须打到内部服务 |
| XSS | 自XSS不要报 | alert(1)≠漏洞 |
| SQLi | Error-based优先 | 不要只报错误消息 |
| RCE | SSRF→metadata→RCE是常见链 | 必须证明用户输入到达 |
