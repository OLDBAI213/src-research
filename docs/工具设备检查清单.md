# 工具设备检查清单

**每次SRC任务开始前必做。不是建议，是强制。**

---

## 一、网络连通性

```bash
# 外网连通
curl -s --noproxy "*" -m 5 -o /dev/null -w "%{http_code}" "https://google.com"
# 期望: 200

# GitHub API
curl -s --noproxy "*" -m 5 -o /dev/null -w "%{http_code}" "https://api.github.com"
# 期望: 200

# 代理状态
curl -s -m 5 -o /dev/null -w "%{http_code}" "http://127.0.0.1:10809"
# 期望: 连接成功或拒绝（不是超时）

# DNS解析
nslookup target.com
# 确认目标域名能解析
```

**断了怎么办**：
- 代理没开 → 提醒老白开代理，或用 `--noproxy` 绕过
- 外网不通 → 不能测试线上目标，但可以做本地分析（JS逆向、APK反编译、代码审计）
- DNS不通 → 目标可能在内网，需要VPN或换入口

## 二、登录态

```bash
# 漏洞盒子
curl -s --noproxy "*" -m 10 "https://vapi.vulbox.com/api/user/info" \
  -H "Cookie: $(cat cookies/vulbox_butian.json | jq -r '.[] | select(.domain | contains("vulbox")) | "\(.name)=\(.value)"' | tr '\n' ';')"
# 期望: {"code":0,"data":{"username":"..."}}

# 补天
curl -s --noproxy "*" -m 10 "https://www.butian.net/" \
  -H "Cookie: ..."
# 期望: 返回登录后页面
```

**过期怎么办**：
- 不是说"硬门"就完了
- 先检查有没有保存的浏览器profile可以用
- 有的话启动有头浏览器，让老白扫码登录
- 没有的话记录下来，先做不需登录的工作（被动侦察、JS分析、APK逆向）

## 三、浏览器

```bash
# Chrome/Edge 远程调试端口
curl -s --noproxy localhost -m 3 "http://localhost:9222/json/version" 2>/dev/null
curl -s --noproxy localhost -m 3 "http://localhost:9333/json/version" 2>/dev/null
curl -s --noproxy localhost -m 3 "http://localhost:9444/json/version" 2>/dev/null
# 期望: 有一个返回JSON

# Playwright
npx playwright --version 2>/dev/null || echo "Playwright不可用"
```

**挂了怎么办**：
- 端口被占 → 杀掉占用进程，或换端口
- Playwright不可用 → 用CDP直连Chrome/Edge
- CDP也不行 → 用curl做HTTP测试，截图用其他方式

## 四、安全工具

```bash
# subfinder
which subfinder 2>/dev/null && subfinder -version 2>&1 | head -1

# httpx
which httpx 2>/dev/null && httpx -version 2>&1 | head -1

# nuclei
which nuclei 2>/dev/null && nuclei -version 2>&1 | head -1

# nmap
which nmap 2>/dev/null && nmap --version 2>&1 | head -1

# ffuf
which ffuf 2>/dev/null && ffuf -V 2>&1 | head -1

# Python
python --version 2>&1
pip list 2>/dev/null | grep -iE "requests|beautifulsoup|scapy|playwright"
```

**缺了怎么办**：
- 写Python脚本替代（requests + urllib 能做80%的HTTP测试）
- 用curl替代命令行工具
- 用浏览器替代扫描器
- **永远有替代方案，没有"做不了"**

## 六、不能放弃的原则

### 工具挂了 → 换工具
| 挂了的工具 | 替代方案 |
|---|---|
| web_extract被限流 | curl + GitHub API |
| subfinder不可用 | 手动DNS枚举 + 子域字典 |
| nuclei不可用 | curl逐个测已知路径 |
| 浏览器CDP连不上 | curl直接发HTTP请求 |
| Playwright不可用 | CDP直连Chrome |
| 外网不通 | 本地分析（JS/APK/代码） |
| 登录态过期 | 先做不需登录的工作 |
| 代理挂了 | --noproxy绕过或换代理 |

### 入口挂了 → 换入口
| 被封的入口 | 替代入口 |
|---|---|
| Web端被封 | 移动端APP/小程序 |
| 主域名被封 | 子域名/旁站/C段 |
| API端点被封 | WebSocket/gRPC/GraphQL |
| 登录被限速 | 换IP/换账号/等待 |
| 验证码挡住 | 换时间段/换入口/人工介入 |

### 路线死了 → 换路线
| 死掉的路线 | 替代路线 |
|---|---|
| SQL注入打不进 | 转XSS/IDOR/逻辑漏洞 |
| 认证绕过试完 | 转越权/信息泄露 |
| Web端挖不动 | 转APP/小程序/小程序 |
| 黑盒打不进 | 找源码泄露/开源组件 |
| 正面打不进 | 找旁站/子域/历史版本 |
