# 靶场平台研究

## 平台对比

| 平台 | 特点 | 免费内容 | 价格 | 适合阶段 |
|---|---|---|---|---|
| **TryHackMe** | 引导式学习路径，新手友好 | 80%免费，每天1小时限制 | $14/月 | ⭐⭐⭐⭐⭐ 入门首选 |
| **Hack The Box** | 全球最强，真实靶机 | Starting Point免费 | $14/月 | ⭐⭐⭐⭐ 进阶 |
| **VulnHub** | 免费下载靶机，本地搭建 | 全部免费 | 免费 | ⭐⭐⭐ 本地练习 |
| **Root-Me** | 608个分级挑战 | 部分免费 | €12/月 | ⭐⭐⭐⭐ 练手 |
| **Exploit-DB** | 漏洞利用代码库 | 全部免费 | 免费 | ⭐⭐⭐ 参考 |
| **CTFtime** | CTF赛事汇总 | 信息免费 | 免费 | ⭐⭐ 竞赛 |

## TryHackMe（最推荐）

### 学习路径
1. **Web Fundamentals** — Web基础（必做）
2. **Jr Penetration Tester** — 初级渗透测试
3. **Web Application Pentesting** — Web应用渗透
4. **Complete Beginner** — 完整入门路径

### 免费能做什么
- 大部分房间免费
- 每天1小时Web-based lab限制
- 学习路径中有些订阅专属房间可跳过
- 核心知识都能免费学到

### 跟我们SRC方法论的整合
- Web Fundamentals → Phase 2（映射）的基础知识
- Jr Penetration Tester → Phase 3（发现）的漏洞原理
- Web Application Pentesting → Phase 4（证明）的利用技术
- 每个房间都用八步方法论跑一遍

## Hack The Box

### 路径
1. **Starting Point** — 入门（免费）
2. **Easy boxes** — 简单靶机
3. **Medium boxes** — 中等难度
4. **Pro Labs** — 企业级渗透（Dante/Offshore）

### 跟我们的关系
- Starting Point 适合入门
- Easy/Medium boxes 适合练手
- 比TryHackMe更接近真实环境

## VulnHub

### 用法
1. 下载.ova文件
2. 在VirtualBox/VMware中导入
3. 启动靶机
4. 从外部渗透

### 优点
- 完全免费
- 离线可用
- 真实环境（不是网页模拟）

### 缺点
- 需要本地虚拟机
- 没有引导，需要自己摸索

## Exploit-DB

### 用法
- 搜索已知漏洞利用代码
- 配合SearchSploit命令行工具
- 在SRC中查找目标软件的已知漏洞

### 跟SRC的整合
- Phase 3发现已知软件漏洞时使用
- 搜索目标版本的exploit
- 参考但不直接执行（需要适配）

## 推荐学习顺序

### 第1周：TryHackMe Web Fundamentals
- 注册免费账号
- 完成Web Fundamentals路径
- 每个房间用八步方法论跑

### 第2周：TryHackMe Jr Penetration Tester
- 完成Web相关房间
- 学习SQLi/XSS/IDOR/SSRF原理

### 第3周：Hack The Box Starting Point
- 注册免费账号
- 完成Starting Point
- 对比TryHackMe的体验

### 第4周：VulnHub本地练习
- 下载1-2个靶机
- 在本地虚拟机中渗透
- 完整走八步方法论

### 持续：Exploit-DB参考
- 遇到已知软件时查exploit
- 学习exploit的构造方式
