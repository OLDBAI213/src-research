# 网安必读书籍研究

## 按SRC方向优先级排序

### 最优先（直接对应我们的SRC方向）

| 书 | 豆瓣 | 内容 | 对我们有什么用 |
|---|---|---|---|
| 《Web渗透测试实战》 | 9.1 | Web安全漏洞原理+利用+防御 | Phase 3发现阶段的理论基础 |
| 《网络攻击与防御》 | 9.2 | 攻击流程+主流攻防技术 | 整体攻防框架 |

#### 《Web渗透测试实战》
- 覆盖：SQL注入/XSS/CSRF/文件上传/目录遍历/认证绕过
- 特点：实战导向，有案例和工具使用
- 怎么读：按SRC方法论的Phase 3查对应章节
- 重点章节：SQL注入原理→XSS分类→IDOR检测→SSRF利用

#### 《网络攻击与防御》
- 覆盖：攻击流程+攻击技术+防御技术+恶意代码+安全设备
- 特点：理论+实战结合，体系化
- 怎么读：重点读"攻击流程"和"常见攻击技术"两章
- 补我们缺的：系统化的攻击思维框架

## 读法（不是从头啃）

### 按SRC方法论阶段读

| 方法论阶段 | 对应书+章节 |
|---|---|
| Phase 1 侦察 | 《Web渗透》"信息收集"章节 |
| Phase 2 映射 | 《Web渗透》"Web应用架构"章节 |
| Phase 3 发现 | 《Web渗透》各漏洞类型章节（重点） |
| Phase 4 证明 | 《网络攻击与防御》"利用技术"章节 |
| Phase 5 报告 | 《网络攻击与防御》"渗透测试报告"章节 |

### 实践验证读法
1. 先在靶场（TryHackMe）遇到一个漏洞类型
2. 回来查对应书籍章节
3. 理解原理后再打靶场
4. 对比书上的方法和我们方法论的差异
5. 更新攻击记忆库

## 跟我们现有知识的对比

| 我们已有的（实践） | 书里补的（理论） | 差距 |
|---|---|---|
| IDOR测试方法 | IDOR原理+分类+利用链 | 我们会测但不理解为什么有效 |
| XSS payload | XSS类型+DOM分析+CSP绕过原理 | 我们会用但不懂底层 |
| SQLi测试 | SQL注入原理+数据库结构+盲注技术 | 我们会Error-based但不懂盲注 |
| SSRF利用 | SSRF原理+云metadata+内部网络 | 我们知道要打169.254但不懂原理 |

**核心差距**：我们会"怎么做"但不理解"为什么这样做"。书补理论，靶场练实践。
